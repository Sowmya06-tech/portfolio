# Sowmya — Marketing, GTM & Growth

A colourful, editorial personal marketing portfolio built as a lightweight static website.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Add real case-study images/results where placeholders are appropriate.
3. Add your LinkedIn URL.
4. Deploy to Vercel, Netlify, GitHub Pages, or any static host.

The site deliberately avoids invented client results, testimonials, logos, or metrics.
